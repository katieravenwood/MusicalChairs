Try the calendar

  1. Public calendar: filter dates or choose a first name. Click a performance for its roster and conflicts. Download a snapshot of that player’s dates.
  2. Staffing editor: choose a demo musician. Only their eligible chairs appear. Select a performance, update a seat assignment or mark players unavailable, then select Save this seat. Each popup shows that performance only.
  3. Administrator: open Administration. Players, shows, chairs, performance dates, and bulk rules load automatically. Preview bulk dates before creating them. New seats are blank and need coverage.
  4. Use Public Calendar in the editor header to see your saved changes. Subscriptions exist only in the public view.
